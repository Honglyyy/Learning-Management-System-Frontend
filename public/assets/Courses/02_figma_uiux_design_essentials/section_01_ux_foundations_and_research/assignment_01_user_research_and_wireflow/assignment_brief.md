# Assignment 1: User Research & Wireflow

### Objective
Conduct discovery research and build low-fidelity wireframes for a personal finance mobile app.

### Deliverables
- 2 validated user personas with journey maps.
- Minimum 8 low-fidelity mobile screens created on an 8pt baseline grid in Figma.
- Documented user flow arrows demonstrating primary onboarding and transaction paths.
