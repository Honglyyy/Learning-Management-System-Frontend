# Lesson 1.1: The 5 Stages of Design Thinking

## 1. Learning Objectives
- Apply the 5-stage Design Thinking framework (Stanford d.school model).
- Create actionable empathy maps and user personas from raw qualitative interview notes.
- Translate user friction points into 'How Might We' (HMW) design opportunities.

## 2. Core Methodology
1. **Empathize**: Conduct contextual inquiries and user interviews.
2. **Define**: Formulate clear problem statements focusing on unmet user needs.
3. **Ideate**: Brainstorm crazy 8s, concept sketches, and feature roadmaps.
4. **Prototype**: Construct low to high fidelity artifacts in Figma.
5. **Test**: Put interactive prototypes in front of real users to validate assumptions.
